Act III · 07 / 08
Before / After

From three sources to one

Before

Defined separately

  • Each skill set its own colors and type sizes
  • Docs, templates and validators each kept their own values
  • The three never quite agreed
After

One token set, built out

  • Docs, templates and validators all generate from one token set
  • Contrast is checked at build time
  • Minimum type sizes are checked at build time
